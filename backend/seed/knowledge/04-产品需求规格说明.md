# 产品需求规格说明（PRD）

## 1. 概述

本文档面向企业协同办公平台的报销核算模块，描述其核心计算规则与数据口径，供开发、测试与实施人员参考。

### 1.1 适用范围

- 适用于员工差旅、招待、采购三类费用的报销核算；
- 适用于财务主管与总经理两级审批流程；
- 金额单位统一为人民币元，保留两位小数。

### 1.2 术语表

| 术语 | 说明 | 示例 |
| --- | --- | --- |
| 报销金额 | 单据实际可报销金额 | 1280.50 |
| 起征线 | 需上级复核的最低金额 | 5000 |
| 税率 | 含税换算使用的增值税率 | 6% |

## 2. 核算规则

报销总额由各项明细累加得到：

$$
\text{报销总额} = \sum_{i=1}^{n} \text{明细金额}_i
$$

> 注意：当单笔明细金额超过 5000 元时，需要总经理额外审批，审批链路为「部门负责人 → 财务主管 → 总经理」。

### 2.1 税额换算

含税金额与不含税金额的换算关系为行内公式 $A_{含} = A_{不含} \times (1 + r)$，其中 $r$ 为税率。

### 2.2 分段计算示例

```python
def total(items):
    return round(sum(i["amount"] for i in items), 2)

items = [{"amount": 320.5}, {"amount": 960.0}]
print(total(items))  # 1280.5
```

## 3. 验收标准

1. 明细累加结果正确；
2. 超过起征线的单据自动进入三级审批；
3. 历史单据可追溯，不可越权查看。

以上规则生效后，报销核算的平均处理时长期望缩短约 $25\%$。
