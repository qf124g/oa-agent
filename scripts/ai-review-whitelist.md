# AI Review 误报白名单

> 已确认的误报模式：审查时命中以下模式一律不报告。
> 每次人工复核确认误报后，把对应模式追加到本文件，随仓库提交。

## 已确认的误报模式

- `catch { return false }` / 空 catch 块：store.ts 快照加载失败走种子初始化、parseArgs 解析失败返回空对象，属于「消除 fallback 触发场景」设计下的预期行为，不是缺陷
- 内存存储无数据库：backend 使用内存 Map + JSON 快照是项目既定架构决策，不报告「应使用数据库」类意见
- 密码明文 `123456`：种子演示数据的既定约定，不报告安全问题
- `any` 类型出现在第三方库类型缺失处（如 pdf-parse）：属于已知限制，不报告
